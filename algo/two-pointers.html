双指针

双指针技巧通过维护两个索引（指针）避免暴力 O(n²) 嵌套循环，将问题降至 O(n) 或 O(n log n)。四种模式：对撞指针（两端向中间，有序数组对和/三数之和）、快慢指针（链表环/中点检测）、滑动窗口（最长/最短子串）、归并双指针（有序序列合并/交集）。核心思路是利用数据的有序性或单调性减少无效比较。

核心术语
  • 对撞指针两端向中间，利用有序性，O(n) 解有序 Two Sum。
  • 快慢指针slow 步1，fast 步2，检测环和中点。
  • 滑动窗口right 扩张，left 收缩，维护窗口不变量。
  • 归并双指针两有序序列各一指针，取小者推进。

对撞指针

  • 前提：数组有序（或排序后处理），利用单调性
  • 若 a[l]+a[r] < target：l++ 增大和
  • 若 a[l]+a[r] > target：r-- 减小和
  • 正确性：单调性保证不会漏解
// Two Sum II（有序数组）O(n) func twoSum(nums []int, target int) []int { l, r := 0, len(nums)-1 for l < r { sum := nums[l] + nums[r] if sum == target { return []int{l+1, r+1} } if sum < target { l++ } else { r-- } } return nil } // 三数之和 O(n^2) func threeSum(nums []int) [][]int { sort.Ints(nums) var res [][]int for i := 0; i < len(nums)-2; i++ { if i > 0 && nums[i] == nums[i-1] { continue } l, r := i+1, len(nums)-1 for l < r { s := nums[i]+nums[l]+nums[r] if s == 0 { res = append(res, []int{nums[i],nums[l],nums[r]}) for l < r && nums[l] == nums[l+1] { l++ } for l < r && nums[r] == nums[r-1] { r-- } l++; r-- } else if s < 0 { l++ } else { r-- } } } return res }

快慢指针

// Floyd 判环算法 // 若有环：fast 追上 slow；相遇点距环入口的距离 = 头到环入口距离 func detectCycle(head *ListNode) *ListNode { slow, fast := head, head for fast != nil && fast.Next != nil { slow = slow.Next fast = fast.Next.Next if slow == fast { // 找入口：一个指针从头，一个从相遇点，同步走 ptr := head for ptr != slow { ptr = ptr.Next slow = slow.Next } return ptr } } return nil } // 找链表中点（偶数长度取前半段末尾） func midNode(head *ListNode) *ListNode { slow, fast := head, head for fast.Next != nil && fast.Next.Next != nil { slow = slow.Next fast = fast.Next.Next } return slow }

滑动窗口

  • right 扩张：将 s[right] 加入窗口，更新窗口状态
  • 当窗口"不合法"或"可以收缩"时，left++，更新状态
  • 每次更新答案（或只在合法时更新）
  • 关键：准确定义"窗口满足条件"的不变量
// 最长无重复字符子串 O(n) func lengthOfLongestSubstring(s string) int { freq := map[byte]int{} left, res := 0, 0 for right := 0; right < len(s); right++ { freq[s[right]]++ for freq[s[right]] > 1 { // 有重复，收缩左边 freq[s[left]]-- left++ } res = max(res, right-left+1) } return res } // 最小覆盖子串（包含所有 t 中字符） // 核心：need 记录还需要多少个字符满足要求 // valid 记录已满足要求的字符种数 func minWindow(s string, t string) string { need, window := map[byte]int{}, map[byte]int{} for i := 0; i < len(t); i++ { need[t[i]]++ } left, right, valid := 0, 0, 0 start, minLen := 0, math.MaxInt for right < len(s) { c := s[right]; right++ if need[c] > 0 { window[c]++ if window[c] == need[c] { valid++ } } for valid == len(need) { if right-left < minLen { start=left; minLen=right-left } d := s[left]; left++ if need[d] > 0 { if window[d] == need[d] { valid-- } window[d]-- } } } if minLen == math.MaxInt { return "" } return s[start:start+minLen] }

归并双指针

// 合并两有序数组 O(m+n) func merge(nums1 []int, m int, nums2 []int, n int) { // 从后往前，避免覆盖 i, j, k := m-1, n-1, m+n-1 for i >= 0 && j >= 0 { if nums1[i] > nums2[j] { nums1[k] = nums1[i]; i-- } else { nums1[k] = nums2[j]; j-- } k-- } for j >= 0 { nums1[k] = nums2[j]; k--; j-- } } // 两排序数组交集 func intersect(a, b []int) []int { sort.Ints(a); sort.Ints(b) var res []int i, j := 0, 0 for i < len(a) && j < len(b) { if a[i] == b[j] { res = append(res, a[i]); i++; j++ } else if a[i] < b[j] { i++ } else { j++ } } return res }

接雨水（经典对撞指针）

  • 暴力：O(n²)，每个位置向左右扫描找最大高度
  • 对撞指针：O(n)，用 leftMax/rightMax 追踪已扫描到的最大值
  • 关键洞察：water[i] = min(leftMax, rightMax) - height[i]，某一侧的 max 已确定就可以算该位置的水量
func trap(height []int) int { l, r := 0, len(height)-1 leftMax, rightMax := 0, 0 res := 0 for l < r { if height[l] < height[r] { if height[l] >= leftMax { leftMax = height[l] } else { res += leftMax - height[l] } l++ } else { if height[r] >= rightMax { rightMax = height[r] } else { res += rightMax - height[r] } r-- } } return res }

适用场景与选择

  • 对撞指针：有序数组/字符串，找两个满足条件的元素（和/差/乘积），判断回文
  • 快慢指针：链表环检测、中点、倒数第 k 个、寻找重复数（数组版 Floyd）
  • 滑动窗口：字符串/子数组最长/最短满足条件的连续段，窗口内元素有单调性约束
  • 归并指针：两个有序序列的合并/交集/差集，合并 k 个有序链表（+ 堆）
  • 注意：无序数组用对撞指针前要先排序（O(n log n)），可能影响时间复杂度
  • 滑动窗口 vs 前缀和：窗口大小可变用滑动窗口；固定大小或非连续用前缀和
