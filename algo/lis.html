Go 代码

func lis(nums []int) int { tails := []int{} for _, n := range nums { pos := sort.SearchInts(tails, n) if pos == len(tails) { tails = append(tails, n) } else { tails[pos] = n } } return len(tails) }

算法原理

Patience Sort 思路：将每个元素放入第一个顶部 ≥ 它的牌堆；若无，则新建牌堆。牌堆数量即为 LIS 长度。

O(n²) DP：dp[i] = 以 arr[i] 结尾的最长递增子序列长度。dp[i] = max(dp[j]+1) 其中 j<i 且 arr[j]<arr[i]。

关键洞察：二分搜索找插入位置，每次操作 O(log n)，共 n 次，总复杂度 O(n log n)。
