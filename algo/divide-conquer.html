分治

分治（Divide and Conquer）将大问题递归分解为相同结构的子问题，每层只需处理合并逻辑，整体复杂度通过主定理分析。经典实例：归并排序（O(n log n)）、快速排序、二分搜索、快速幂、Karatsuba 大整数乘法、FFT 多项式乘法。分治与动态规划的区别：DP 子问题重叠且需要记忆化，分治子问题独立不重叠。

归并排序快速幂二分主定理FFT逆序对
核心术语
  • 分治三步骤Divide → Conquer（递归）→ Combine（合并）。
  • 主定理T(n)=aT(n/b)+f(n) 的复杂度分析，比较 f(n) 与 n^log_b(a)。
  • 归并排序分治经典，稳定 O(n log n)，可用于求逆序对。
  • Karatsuba 乘法3次递归替代4次，O(n^1.585) 大整数乘法。

主定理

T(n) = aT(n/b) + f(n)，a≥1, b>1，f(n) 是合并代价

Case 1: f(n) = O(n^(log_b a - ε)) → T(n) = Θ(n^log_b a) [递归主导] Case 2: f(n) = Θ(n^log_b a) → T(n) = Θ(n^log_b a · log n) Case 3: f(n) = Ω(n^(log_b a + ε)) → T(n) = Θ(f(n)) [合并主导]
  • 归并排序：T(n) = 2T(n/2) + O(n)，Case 2 → O(n log n)
  • 二分搜索：T(n) = T(n/2) + O(1)，Case 2 → O(log n)
  • Karatsuba：T(n) = 3T(n/2) + O(n)，log₂3≈1.585，Case 1 → O(n^1.585)
  • Strassen 矩阵乘法：T(n) = 7T(n/2) + O(n²)，→ O(n^2.807)

归并排序 & 逆序对

// 归并排序（同时统计逆序对） var invCount int func mergeSort(nums []int, l, r int) { if l >= r { return } mid := (l + r) / 2 mergeSort(nums, l, mid) mergeSort(nums, mid+1, r) merge(nums, l, mid, r) } func merge(nums []int, l, mid, r int) { tmp := make([]int, r-l+1) i, j, k := l, mid+1, 0 for i <= mid && j <= r { if nums[i] <= nums[j] { tmp[k] = nums[i]; i++ } else { // nums[i..mid] 都比 nums[j] 大（左半有序） invCount += mid - i + 1 tmp[k] = nums[j]; j++ } k++ } for i <= mid { tmp[k] = nums[i]; i++; k++ } for j <= r { tmp[k] = nums[j]; j++; k++ } copy(nums[l:r+1], tmp) }

快速幂（矩阵快速幂）

// 快速幂 O(log n) func pow(base, exp, mod int) int { res := 1 base %= mod for exp > 0 { if exp & 1 == 1 { res = res * base % mod } base = base * base % mod exp >>= 1 } return res } // 矩阵快速幂（斐波那契第 n 项） // [F(n+1)] [1 1]^n [F(1)] // [F(n) ] = [1 0] * [F(0)] type Matrix [2][2]int64 func matMul(a, b Matrix) Matrix { var c Matrix for i := 0; i < 2; i++ { for j := 0; j < 2; j++ { for k := 0; k < 2; k++ { c[i][j] += a[i][k] * b[k][j] } } } return c } func fibonacci(n int) int64 { if n <= 1 { return int64(n) } base := Matrix{{1,1},{1,0}} res := Matrix{{1,0},{0,1}} // 单位矩阵 n-- for n > 0 { if n&1 == 1 { res = matMul(res, base) } base = matMul(base, base) n >>= 1 } return res[0][0] }

二分搜索（分治的特例）

// 通用二分模板（查找满足条件的最左位置） func lowerBound(nums []int, target int) int { l, r := 0, len(nums) for l < r { mid := (l + r) / 2 if nums[mid] < target { l = mid + 1 } else { r = mid } } return l // 返回第一个 >= target 的位置 } // 二分答案：找最小满足条件的 k // 例：最小化最大分割子数组和（分割数组） func splitArray(nums []int, k int) int { lo, hi := slices.Max(nums), sum(nums) for lo < hi { mid := (lo + hi) / 2 if canSplit(nums, k, mid) { hi = mid } else { lo = mid + 1 } } return lo } // 检查是否能以 mid 为最大和将数组分为 k 段 func canSplit(nums []int, k, limit int) bool { count, cur := 1, 0 for _, n := range nums { if cur+n > limit { count++; cur = 0 } cur += n } return count <= k }

Karatsuba 大整数乘法

  • 普通长乘法：O(n²)，n 位数需要 n² 次单位乘法
  • 朴素分治（四次递归）：T(n) = 4T(n/2) + O(n) → O(n²)，无提升
  • Karatsuba 关键：用 3 次递归替代 4 次
// 设 x = a·B + b，y = c·B + d（B = 10^(n/2)） // 普通：xy = ac·B² + (ad+bc)·B + bd （4次乘法） // Karatsuba： // z0 = b·d // z2 = a·c // z1 = (a+b)·(c+d) - z2 - z0 = ad+bc （只用1次乘法） // xy = z2·B² + z1·B + z0 // T(n) = 3T(n/2) + O(n) → O(n^log2(3)) ≈ O(n^1.585) // Python: 大整数乘法默认使用 Karatsuba // Go crypto/big 包实现了 Karatsuba 和 Toom-Cook3

分治 vs 动态规划

  • 分治：子问题相互独立，不重叠，可以直接递归解决
  • 动态规划：子问题重叠，需要记忆化（memo）或自底向上计算避免重复
  • 快速排序：子问题不重叠（左/右各自排序）→ 分治
  • 最长公共子序列：dp[i][j] 依赖 dp[i-1][j-1]，重叠 → DP
  • FFT（快速傅里叶变换）：分治 + 蝴蝶运算，O(n log n) 多项式乘法
  • 适用分治的信号：问题可以自然地对半分，合并代价不高于子问题规模
