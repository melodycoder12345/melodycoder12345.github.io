单调队列 / 栈

单调结构维护候选集合的有序性，让窗口最值、下一个更大元素等问题避免重复比较，实现均摊 O(1) 查询。

核心术语
单调队列队列内元素按值保持递增或递减，同时按时间过期。
单调栈栈内维护单调性，用于寻找相邻支配关系。
候选淘汰新元素让某些旧元素永久失去成为答案的机会。

背景

"单调"指维护一个有序结构，使得新元素进入时可以 O(1) 淘汰不再有用的旧候选。核心思想：如果一个旧元素在所有未来查询中都不可能成为答案，就立即丢弃它。

两类典型问题：

  • 单调栈：对每个元素找到"下一个更大/更小"的位置（Next Greater Element）
  • 单调队列：在固定大小的滑动窗口中维护最大/最小值

暴力做法对每个元素向后扫描是 O(n²)，单调结构让每个元素最多入队/出队一次，总复杂度 O(n)。

为什么叫"单调"：栈/队列中的元素始终保持单调递增或单调递减的顺序。这个不变量让队首/栈顶始终保存当前最优候选，无需遍历整个结构。

运行机制：单调栈

以"下一个更大元素"为例，维护一个递减栈（栈底到栈顶值递减）：

  • 遍历数组，当前元素比栈顶大时，栈顶的"下一个更大元素"就是当前元素，弹出并记录答案。
  • 重复弹出直到栈为空或栈顶元素更大。
  • 将当前元素（下标）入栈，等待未来被弹出时获得答案。
  • 遍历结束后栈中剩余的元素没有"下一个更大"，答案为 -1。
// Next Greater Element：对每个位置找右边第一个比它大的元素
func nextGreater(nums []int) []int {
    n := len(nums)
    ans := make([]int, n)
    for i := range ans {
        ans[i] = -1 // 默认没有更大的
    }
    stack := []int{} // 存下标，栈内对应值递减

    for i := 0; i < n; i++ {
        for len(stack) > 0 && nums[i] > nums[stack[len(stack)-1]] {
            top := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            ans[top] = nums[i]
        }
        stack = append(stack, i)
    }
    return ans
}
// 输入: [2, 1, 2, 4, 3]
// 输出: [4, 2, 4, -1, -1]

运行机制：单调队列

以"滑动窗口最大值"为例，维护一个递减双端队列（队首到队尾值递减）：

  • 队尾淘汰：新元素从队尾进入前，弹出所有值比它小的元素——它们已被"支配"（更小且更老，永远不可能成为窗口最大值）。
  • 队首过期：队首元素如果下标超出窗口左边界，从队首弹出（时间淘汰）。
  • 答案获取：队首始终是当前窗口的最大值，O(1) 读取。

关键不变量：队列中的元素从队首到队尾值递减、下标递增。

// LeetCode 239: Sliding Window Maximum
func maxSlidingWindow(nums []int, k int) []int {
    deque := []int{} // 存下标，对应值递减
    ans := []int{}

    for i := 0; i < len(nums); i++ {
        // 1. 移除过期元素（超出窗口左边界）
        for len(deque) > 0 && deque[0] <= i-k {
            deque = deque[1:]
        }
        // 2. 维护递减：弹出比当前值小的队尾
        for len(deque) > 0 && nums[deque[len(deque)-1]] <= nums[i] {
            deque = deque[:len(deque)-1]
        }
        // 3. 入队
        deque = append(deque, i)
        // 4. 窗口形成后记录答案
        if i >= k-1 {
            ans = append(ans, nums[deque[0]])
        }
    }
    return ans
}
// 输入: nums=[1,3,-1,-3,5,3,6,7], k=3
// 输出: [3,3,5,5,6,7]

复杂度：每个元素入队/出队各最多一次，总 O(n)。空间 O(k)——队列中最多 k 个元素。

Go deque 实现注意：Go 标准库无 deque，可用 slice 模拟（队首弹出 dq = dq[1:]），生产环境建议用 container/list 或环形缓冲避免内存泄漏。

核心技巧总结

  • 存下标不存值：下标同时能判断过期和比较大小，信息量更大。
  • 先弹后压：新元素入栈/入队前先维护单调性（弹出被支配者），再入栈。
  • 循环数组处理：对于"环形下一个更大元素"（LC 503），遍历 2n 次，下标 mod n。
  • 多栈/多队列：复杂场景（如同时求左右边界）可维护两个栈分别处理。
  • 初始哨兵：在数组末尾或开头加一个极小值哨兵，确保栈中所有元素都能被弹出，避免遗漏。

常见误区

误区 1：混淆栈和队列的使用场景
// 错误：用栈解决窗口最大值
// 栈只能从一端操作，无法移除过期的队首
stack := []int{}
// 无法 O(1) 移除最早进入的元素

栈没有"队首过期淘汰"的能力，窗口最值必须用双端队列。

// 正确选择：
// 下一个更大元素 → 单调栈（只需后进先出）
// 窗口最大值 → 单调队列（需要两端操作）
//   队尾淘汰被支配者
//   队首淘汰过期者

栈解决"下一个"关系，队列解决"窗口极值"。

误区 2：存值而非存下标导致无法判断过期
// 错误：队列里存值
deque := []int{} // 存的是 nums[i]
// 无法判断队首是否已滑出窗口
// 因为不知道它的原始位置

相同值可能出现在不同位置，光靠值无法判断是否过期。

// 正确：队列里存下标
deque := []int{} // 存 i
// 判断过期：deque[0] <= i - k
// 比较大小：nums[deque[...]]

下标可以同时用于过期判断和值比较，信息更完整。

误区 3：弹出条件用 < 还是 <= 搞混
// 求最大值时用严格小于
for len(dq) > 0 && nums[dq[len(dq)-1]] < nums[i] {
    // 等于的元素不弹出
}
// 问题：相等元素留在队列中，
// 队首过期时可能丢失正确答案

如果等值元素不弹出，队列可能变长影响过期判断的正确性。

// 正确：用 <= 弹出（保留最新的相等元素）
for len(dq) > 0 && nums[dq[len(dq)-1]] <= nums[i] {
    dq = dq[:len(dq)-1]
}
// 相等时新元素更晚过期，留新弃旧更安全

等值时保留更新的下标，它能在窗口中存活更久。

面试问答

单调栈的时间复杂度为什么是 O(n)？▶
每个元素最多入栈一次、出栈一次。虽然外层有一个 for 循环，内层有一个 while 弹出循环，但 while 弹出的总次数不会超过 n（因为最多入栈 n 次）。所以总操作 2n 次，即 O(n)。这是经典的均摊分析。
单调栈能解决哪些变体问题？▶
常见变体：
1. 下一个更大/更小元素（Next Greater/Smaller）
2. 前一个更大/更小元素（Previous Greater/Smaller）：从左到右遍历，当前栈顶就是答案
3. 柱状图最大矩形（LeetCode 84）：对每个柱子找左右第一个更矮的位置
4. 接雨水（LeetCode 42）：找左右第一个更高的柱子
5. 股票跨度问题（LeetCode 901）：找前一个更大元素的距离
如何判断用递增栈还是递减栈？▶
取决于你要找什么：
- 找下一个更大元素：维护递减栈（栈顶最小），新元素比栈顶大时弹出
- 找下一个更小元素：维护递增栈（栈顶最大），新元素比栈顶小时弹出

记忆方法：栈内保持的单调性和你要寻找的关系相反。找"更大"用递减栈，因为递减意味着一旦遇到更大的就破坏了单调性，正是触发弹出回答的时机。
单调队列和优先队列（堆）解决窗口最值有什么区别？▶
单调队列：O(n) 总时间，每个元素入队出队各一次。空间 O(k)。实现简单但只能处理滑动窗口场景。

优先队列/堆：每次插入 O(log n)，总时间 O(n log n)。优势是更通用，可以处理任意删除、动态大小窗口等复杂场景。

面试中如果是固定大小滑动窗口最值，单调队列是最优解。如果窗口大小不固定或需要支持任意删除，考虑堆+懒删除。

工程应用

  • 实时监控峰值：在最近 5 分钟的指标数据上用单调队列维护 max，O(1) 获取当前窗口峰值用于告警阈值判断。
  • 股票/交易系统：计算最近 N 笔交易的最高/最低价，单调队列比每次遍历快得多。
  • CPU 调度：在任务优先级队列中，新任务进入时淘汰被支配的旧任务（优先级低且截止时间晚）。
  • 柱状图最大矩形（LeetCode 84）：对每个柱子用单调栈找左右第一个更矮的位置，计算最大面积。这是单调栈的经典应用。
  • 接雨水（LeetCode 42）：单调栈找每个位置的左右最高边界，累加容量。

经典题目清单：LC 84（柱状图最大矩形）、LC 42（接雨水）、LC 239（滑动窗口最大值）、LC 496/503（下一个更大元素）、LC 901（股票跨度）、LC 739（每日温度）。

变体与扩展

  • 二维单调栈：LC 85（最大矩形）在每行基础上建柱状图，逐行用单调栈求最大矩形面积。
  • 单调栈 + 动态规划：一些 DP 问题的转移方程可以通过单调栈/队列优化到 O(n)（如 LC 1425 带限制的子序列和）。
  • 差分 + 单调栈：在区间问题中，先做差分再用单调栈处理相邻关系。
  • 离线处理：将查询按右端点排序，用单调栈在线回答（如区间内不同元素数量的某些变体）。

复杂度对比

  • 暴力：对每个元素向后扫描 → O(n²)
  • 单调栈/队列：每个元素最多入栈一次出栈一次 → O(n) 均摊
  • 堆/TreeMap：每次操作 O(log n)，总 O(n log n)。更通用但常数更大。

面试中，如果问题匹配"下一个更大/更小"或"固定窗口极值"模式，优先使用单调结构。如果条件更复杂（动态插入删除），再考虑堆或平衡树。

空间复杂度：单调栈 O(n) 最差情况（如严格递增数组没有弹出），单调队列 O(k) 其中 k 为窗口大小。实际使用中栈/队列大小远小于 n。

面试答题思路

遇到以下关键词时考虑单调栈/队列：

  • "下一个更大/更小的元素" → 单调栈
  • "前一个更大/更小的元素" → 单调栈（遍历方向可能变化）
  • "滑动窗口最大值/最小值" → 单调队列
  • "最大矩形面积" → 单调栈找左右边界
  • "每日温度"/"股票跨度" → 单调栈的距离变体
  • "连续子数组的最大/最小值之和" → 单调栈计算每个元素作为最值的贡献范围

答题模板：明确要维护的单调性方向（递增/递减）→ 决定弹出条件 → 存下标 → 处理边界（哨兵或默认值）。
