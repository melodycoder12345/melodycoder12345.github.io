位运算

位运算直接操作整数的二进制位，时间复杂度 O(1)，在算法竞赛和系统编程中是常用优化手段。核心操作包括 AND/OR/XOR/NOT 和移位，关键技巧包括：Brian Kernighan 算法（清最低位1）、状态压缩 DP（用整数表示集合）、位掩码（权限/标志管理）、Gosper's Hack（枚举子集）。

核心术语
  • 基本位运算AND/OR/XOR/NOT，控制整数的特定位。
  • 移位运算左移乘2，右移除2，注意有符号右移的算术移位。
  • Brian Kernighann &= n-1 清最低有效位，计算 popcount 的关键。
  • 状态压缩 DP用整数位表示集合，2^n 状态的 DP 优化。

基本操作速查

检测第 k 位是否为 1
(n >> k) & 1 == 1
将第 k 位移到最低位后和 1 做 AND
设置第 k 位为 1
n |= (1 << k)
第 k 位 OR 上 1
清除第 k 位（置0）
n &= ~(1 << k)
取反后 AND，第 k 位变 0，其余不变
翻转第 k 位
n ^= (1 << k)
XOR 上 1，0变1，1变0
清除最低有效位
n &= (n - 1)
Brian Kernighan，循环可计算 popcount
提取最低有效位
lowbit = n & (-n)
利用补码，-n = ~n+1，AND 后只剩最低位1

经典题型与技巧

// 1. 判断 2 的幂次 // 2^n 只有 1 个 1，减 1 后全是 1，AND 为 0 func isPowerOfTwo(n int) bool { return n > 0 && (n & (n-1)) == 0 } // 2. 计算 popcount（1 的个数） func popcount(n int) int { count := 0 for n != 0 { n &= n - 1 // 清除最低位 1 count++ } return count } // 也可用：bits.OnesCount(uint(n)) // 3. 只出现一次的数（XOR） // 相同数异或为 0，0 异或任何数为那个数 func singleNumber(nums []int) int { res := 0 for _, n := range nums { res ^= n } return res } // 4. 不用加法做加法（XOR + 进位） func add(a, b int) int { for b != 0 { carry := (a & b) << 1 // 进位 a = a ^ b // 无进位加 b = carry } return a }

状态压缩 DP

  • 用整数的第 i 位表示第 i 个元素是否在集合中
  • 全集：(1<<n) - 1，空集：0
  • 枚举所有子集：for s := mask; s > 0; s = (s-1) & mask
  • 判断 i 是否在集合 s 中：s & (1<<i) != 0
  • 将 i 加入集合 s：s | (1<<i)
  • 将 i 移出集合 s：s & ^(1<<i)

位运算在系统编程中的应用

  • 权限标志：Unix 文件权限 rwxrwxrwx 用 9 位表示，chmod 755 = 0b111101101
  • 布隆过滤器：位数组 + 多个哈希函数，查询时 bits[h(x)] & 1
  • CPU 状态标志：x86 EFLAGS 寄存器每一位是一个标志（ZF/CF/OF）
  • 网络掩码：IP 子网掩码如 /24 = 0xFFFFFF00，ip & mask 得到网络地址
  • 哈希函数：MurmurHash/xxHash 大量使用位混合操作
  • Bitmap 索引：数据库用 bitmap 存储索引，AND/OR 实现集合交并
// 位掩码权限管理 const ( READ = 1 << 0 // 0b001 WRITE = 1 << 1 // 0b010 EXECUTE = 1 << 2 // 0b100 ) perms := READ | WRITE // 拥有读写权限 // 检查权限 if perms & READ != 0 { /* 有读权限 */ } // 撤销写权限 perms &= ^WRITE

高级技巧

  • Gosper's Hack（枚举 k 个1的子集）：按字典序枚举所有恰好有 k 个位为 1 的整数
  • 平行位计数（SWAR）：用分治法在 O(log n) 步内计算 popcount
  • 交换两变量（无临时变量）：a^=b; b^=a; a^=b;（现代代码不推荐，影响优化）
  • 绝对值（无分支）：mask = n >> 31; (n ^ mask) - mask
  • 符号函数：(n >> 31) | ((-n) >>> 31)
// Gosper's Hack：枚举所有 popcount(s) == k 的子集 s := (1 << k) - 1 // 初始：k 个最低位为 1 for s < (1 << n) { // 处理 s c := s & -s r := s + c s = (((r ^ s) >> 2) / c) | r } // 32 位 popcount (SWAR) func popcnt32(x uint32) uint32 { x = x - ((x >> 1) & 0x55555555) x = (x & 0x33333333) + ((x >> 2) & 0x33333333) x = (x + (x >> 4)) & 0x0f0f0f0f return (x * 0x01010101) >> 24 }

常见误区

  • 有符号整数右移：Java/C（signed）是算术右移（高位补符号位），>>> 才是逻辑右移
  • 溢出：1 << 31 在 32 位有符号整数中是负数（-2147483648），用 1 << 62 避免
  • 运算符优先级：& 和 | 优先级低于 ==，必须加括号：(n & 1) == 1
  • Go 中无 >>>：Go 的 >> 对有符号整数是算术移位，需要先转为 uint
  • 位运算不等于逻辑运算：& 和 && 不同，| 和 || 不同，后者有短路求值
