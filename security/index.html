理解对称加密、非对称加密和数字签名的边界；新设计优先 AEAD，RSA 使用 OAEP/PSS 等标准方案，现代 TLS 不再使用静态 RSA 密钥交换。

授权码流程四角色、严格 redirect URI、state 与 PKCE。OAuth 2.0 负责授权；需要登录身份时使用 OpenID Connect 等身份层。

证书链验证（叶证书→中间 CA→根 CA）、Let's Encrypt ACME 自动续签、证书吊销（CRL/OCSP Stapling）、内网 Vault PKI 与 mTLS 双向认证。

密钥管理：Vault

动态凭据（用完即销毁）、租约自动到期、凭据自动轮换、级联吊销应急响应。取代配置文件硬编码，将密码泄漏的危害时间窗口从无限大缩短至分钟级。

容器安全

Trivy 扫描镜像 CVE，securityContext 限制容器权限（非 root/只读文件系统），Seccomp/AppArmor 限制 syscall，K8s RBAC 最小权限，NetworkPolicy 东西流量隔离。

供应链安全

SBOM 提供组件可见性，Cosign/Sigstore 验证制品身份与摘要，Provenance 描述构建来源；这些控制需要组合使用，不能单独证明代码无漏洞或无恶意逻辑。

零信任网络

不按网络位置授予隐式信任，围绕资源做动态认证、授权与持续评估。IAP、mTLS 和 BeyondCorp 是可选实现模式，不是零信任的唯一形态。

学习路径建议

从 对称/非对称加密（密码学基础）→ PKI/证书体系（TLS 信任链）→ OAuth/JWT（身份与授权）→ Web 攻击防御（应用层安全）→ 密钥管理 Vault（凭据生命周期）→ 容器安全（运行时防护）→ 供应链安全（构建链防护）→ 零信任网络（架构级安全）。安全是纵深防御，每一层都不可缺少。
