密钥管理：Vault

将密码、API Key、证书等敏感凭据集中管理，取代在代码或配置文件中硬编码的不安全做法。HashiCorp Vault 提供动态凭据（用完即销毁）、自动轮换、租约管理、细粒度访问策略，极大缩短凭据泄漏的危害时间窗口。

步骤
选择左侧场景，点击「下一步」开始观察。
📄
application.properties
数据库密码明文写在配置文件中
spring.datasource.url=jdbc:mysql://prod-db:3306/app
spring.datasource.username=admin
spring.datasource.password=P@ssw0rd!2024
📦
git push origin main
配置文件随代码进入 Git 历史，永久保存——即使日后删除文件，git log 仍可找回
🔍
黑客扫描公开仓库
自动化工具（truffleHog / git-secrets）匹配密码模式，一旦仓库可见，密码立即暴露
💥
数据库被入侵，数据泄漏
攻击者直连生产数据库，导出所有用户数据，整个过程仅需几分钟
🔄
运维被迫紧急更换密码
需找出所有使用该密码的配置文件 → 修改 → 重新部署 10 个服务 → 协调停机窗口 → 漏改一个导致级联故障
❓
无法审计：谁看过这个密码？
密码存在文件里，没有访问日志，无法回答「哪个 IP 在何时用这个密码访问了数据库」——事后追溯完全失效
🖥 Service
🔐 Vault
🗄 MySQL

静态密码泄漏后

  • 无法确认泄漏时间点
  • 无法追溯谁使用了密码
  • 更换密码需停机重部署
  • Git 历史密码无法真正删除

Vault 动态凭据泄漏后

  • 立即吊销，<1 秒生效
  • Audit Log 完整记录使用历史
  • 合法服务自动重认证恢复
  • 临时账号已自动删除
