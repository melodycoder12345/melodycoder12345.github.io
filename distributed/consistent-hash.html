一致性哈希

一致性哈希把 key 和节点映射到同一条环上，节点变化时只迁移局部 key。

Hash RingVirtual NodeSharding
核心术语
  • Hash Ring固定大小的哈希空间首尾相接。
  • Virtual Node一个物理节点映射多个位置，用来平衡倾斜。
  • Clockwise Lookupkey 顺时针找到第一个节点作为归属。

背景与机制

普通取模分片在节点数变化时会让大量 key 重新映射。一致性哈希用环形空间把变化限制在相邻区间，降低扩缩容迁移成本。

常见误区

  • Redis Cluster 使用 slot，不是严格的一致性哈希环。
  • 一致性哈希减少迁移量，但不能自动解决热点 key。

工程场景

  • 缓存集群、负载均衡、有状态路由和存储分片都会用到稳定映射思想。
  • 扩容评估应关注迁移比例、热点区间和客户端路由刷新。
