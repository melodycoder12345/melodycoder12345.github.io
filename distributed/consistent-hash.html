一致性哈希

一致性哈希把 key 和节点映射到同一条环上，节点变化时只迁移局部 key，扩缩容成本与总节点数无关。

Hash RingVirtual NodeClockwise Lookup
核心术语
  • Hash Ring固定大小的哈希空间首尾相接构成环，节点和 key 都映射到环上的位置。
  • Virtual Node一个物理节点映射到环上多个位置，用来平衡数据倾斜和热点。
  • Clockwise Lookupkey hash 值顺时针遇到的第一个节点就是该 key 的 owner。

背景与机制

普通取模分片在节点数变化时会让大量 key 重新映射。一致性哈希用环形空间把变化限制在相邻区间，降低扩缩容迁移成本。

常见误区

  • Redis Cluster 使用 16384 个 slot，不是严格的一致性哈希环，但思想相通。
  • 一致性哈希减少迁移量，但不能自动解决热点 key，需要虚节点或额外路由策略。

工程场景

  • 缓存集群、负载均衡、有状态路由和存储分片都会用到稳定映射思想。
  • 扩容评估应关注迁移比例、热点区间和客户端路由刷新延迟。

边界与恢复
