推荐学习路径

从策略到实践的系统路径

1测试金字塔 — 先理解分层策略和各层成本，确定在哪一层写什么粒度的测试。
2Mock / Stub / Spy — 掌握 Test Doubles 技术，让单元测试能在隔离状态下快速运行。
3TDD / BDD — 将测试作为设计工具，在编码前通过测试表达期望行为。
4契约测试 — 在微服务场景下，用消费者驱动的契约提前检查已声明的接口兼容性，并保留必要的集成测试。
5负载与压力测试 — 验证系统在真实流量下的容量极限，定位性能瓶颈。
6模糊测试 — 针对 Parser、编解码、协议处理等场景，用自动化变异输入挖掘边界漏洞。
