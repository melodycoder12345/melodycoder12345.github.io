扩散模型

扩散模型通过逐步加噪（前向过程）和学习去噪（逆向过程）来生成图像。DDPM 奠定理论基础，DDIM 加速采样，Stable Diffusion 结合 CLIP 文本引导实现文生图。

DDPM前向扩散去噪Classifier-Free Guidance
核心术语
Forward Process（前向扩散）对数据 x₀ 逐步添加高斯噪声，经过 T 步后变为纯噪声 x_T ~ N(0, I)。这个过程是固定的、无需学习的马尔可夫链：q(x_t|x_{t-1}) = N(x_t; √(1-β_t)·x_{t-1}, β_t·I)。
Denoising（去噪网络）神经网络 ε_θ(x_t, t) 学习预测每步添加的噪声 ε，训练目标是最小化 ||ε - ε_θ(x_t, t)||²。推理时从 x_T 开始，反复去噪直到 x₀。
CFG（Classifier-Free Guidance）推理时混合条件和无条件去噪：ε̂ = ε_uncond + w·(ε_cond - ε_uncond)。w=1 是无引导，w=7.5 是常用默认值，越大文本控制越强但多样性降低。

DDPM vs DDIM

      
DDIM 是对 DDPM 采样过程的重要改进，将采样步数从 1000 步降低到 50 步甚至更少，同时保持生成质量。

      
    
        
  • DDPM：随机采样，每步加入随机噪声，需要完整 T=1000 步，不可复现。每次生成结果不同。
    • 
        
  • DDIM：确定性采样（η=0），跳过大量中间步，50 步即可达到接近 DDPM 的质量，相同种子可复现。
    • 
        
  • 速度对比：DDIM 50 步 ≈ DDPM 1000 步质量，速度快 20 倍。
    • 
        
  • 图像插值：DDIM 的确定性编码让图像空间插值成为可能：encode A → encode B → 插值 latent → decode。
    • 
      

    

    

      
Latent Diffusion（潜在扩散）

      
在像素空间做扩散成本极高（512×512 图像有 786K 像素）。Stable Diffusion 的核心创新是把扩散过程移到 VAE 压缩的低维潜在空间。

      
    
        
  • VAE 编码器：将 512×512×3 图像压缩到 64×64×4 的 latent（压缩比 48×），大幅减少 UNet 的计算量。
    • 
        
  • 在 Latent 空间扩散：前向加噪和逆向去噪都在 64×64×4 空间进行，而非原图空间。
    • 
        
  • VAE 解码器：生成完成后，用 VAE 解码器将 latent 还原为完整像素图像。
    • 
        
  • 效果：计算成本降低 48 倍，同时生成质量几乎不损失，是大规模文生图的基础。
    • 
      

    

    

      
Stable Diffusion 架构

      
Stable Diffusion 将三个组件组合成完整的文生图管线：

      
    
        
  • CLIP 文本编码器：将文本 prompt 编码为 token embedding 序列，通过交叉注意力（Cross-Attention）注入 UNet 的每个层。
    • 
        
  • VAE：编码器压缩图像到 latent，解码器还原 latent 到像素。训练时用真实图像，推理时只用解码器。
    • 
        
  • UNet 去噪网络：以噪声 latent 和时间步 t 为输入，通过残差块+注意力层+交叉注意力，预测噪声 ε，是模型中唯一在推理时运行的神经网络。
    • 
      

      
# Stable Diffusion 推理伪代码
text_emb = clip_encoder(prompt)           # CLIP 文本编码
latent = torch.randn(1, 4, 64, 64)       # 随机初始 latent
for t in reversed(range(T)):             # DDIM 逆向
    noise_pred = unet(latent, t, text_emb)  # 预测噪声
    latent = ddim_step(latent, noise_pred, t)
image = vae_decoder(latent)               # 解码为像素

    

    

      
采样器选择

      
采样器（Scheduler）决定了去噪的具体更新规则，直接影响生成速度和质量。

      
    
        
  • DDIM：经典确定性采样，50 步质量稳定，适合需要可复现结果的场景。
    • 
        
  • DPM-Solver++：多步 ODE 求解器，20-30 步即可达到高质量，目前 Stable Diffusion WebUI 的主流默认。
    • 
        
  • PNDM：拟牛顿方法，比 DDIM 快但偶有质量不稳定问题。
    • 
        
  • Euler/Euler a：最简单快速，30-40 步，适合快速预览；Euler a（ancestral，随机）每次结果不同，Euler 确定性。
    • 
        
  • LCM/SDXL-Turbo：蒸馏后的超快采样，1-4 步即可生成，代价是细节和一致性略差。
    • 
      

      
没有绝对最好的采样器。DPM-Solver++ 2M 在速度和质量的综合表现上目前最均衡，建议从它开始调试。
