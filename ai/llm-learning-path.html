01从这里开始

阶段一：使用大模型与 API

理解调用链路、安全边界和错误恢复；几乎不需要数学。
1. LLM 基础概念先理解 Token、生成、训练与推理。 2. API 调用基础请求、认证、流式消费与错误恢复。 3. Prompt Engineering组织指令、上下文和示例。 4. 上下文长度理解输入预算与超限边界。 5. 结构化输出用 Schema 约束并校验结果。 6. 工具调用理解模型提议与宿主执行的边界。
02完成阶段一后

阶段二：理解 Transformer

按需补向量、Softmax 和梯度，再串联 Tokenization、Embedding 与 Attention。
1. 向量与矩阵Token 向量、点积、形状和矩阵乘法。 2. Softmax 与交叉熵从 Logits 到概率与 Loss。 3. 梯度与反向传播链式法则和一次参数更新。 4. BPE 分词复用现有 Tokenization 主讲页面。 5. Embedding复用现有向量语义与检索页面。 6. Transformer Attention把数学前置装进 Q/K/V 流程。 7. Training Pipeline理解 Loss、Backward 与 Optimizer 的系统位置。
03完成阶段二后

阶段三：从零实现 Mini GPT

把组件组合成一个可运行的小模型，并跟随完整张量流。
Mini GPT 分步实验跟随张量形状，并对照 PyTorch 教学实现。
04完成阶段三后

阶段四：训练算法实验

通过 Loss 曲线理解优化器、学习率、梯度裁剪、正则化与 LoRA。
训练优化实验室识别慢、发散、梯度爆炸与过拟合曲线。 微调 / LoRA继续进入现有参数高效微调页面。

阶段一完成标准

  • 能解释一次模型 API 请求的完整生命周期。
  • 能区分普通响应和流式响应。
  • 知道 API Key 为什么必须保存在服务端。
  • 能识别限流、超时、上下文超限和结果校验失败。

数学从哪里开始

第一阶段几乎不需要数学。第二阶段遇到 Embedding、Attention、Softmax 和训练时，再依次补向量、矩阵、概率、导数和梯度。这样每个公式都有明确用途。

四个阶段均已提供页面与验收入口；仍建议按顺序学习，不必一次看完。
