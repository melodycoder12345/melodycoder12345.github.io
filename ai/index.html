和现有知识的关系

  • RAG 和现有 db/vector.html 强关联：向量索引负责把语义检索做成在线服务。
  • KV Cache 和 cs/cache.html、linux/sequential-io.html 有工程联系：缓存命中、内存带宽和批处理决定吞吐。
  • Agent 工程会连接 Go Web、HTTP、Redis、Kafka：工具调用、异步任务、状态存储和观测链路都依赖后端基础。

学习目标

读完第一版 AI 模块后，应该能回答三个问题：模型为什么能生成文本，在线推理为什么贵且慢，RAG / Agent 为什么不是简单拼 Prompt。页面会避免只堆术语，重点解释机制、权衡、失败模式和工程场景。
