三条安全边界
密钥只放服务端浏览器代码、前端环境变量和公开仓库都不能保存 API Key。
重试必须有上限只对适合重试的错误使用指数退避，并设置总次数、超时和预算。

推荐调用结构

      
// 只在服务端执行
const response = await fetch(process.env.LLM_API_URL, {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.LLM_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ input, stream: true }),
  signal: AbortSignal.timeout(30_000)
});

if (!response.ok) handleModelError(response.status);
for await (const event of readStream(response.body)) {
  validateAndForward(event);
}

      
代码只展示通用调用边界。具体请求字段、事件格式和错误码应以所选服务的当前官方文档为准。

    

    

      
普通响应与流式响应

      
    
        
  • 普通响应：实现简单，必须等完整结果生成后才能展示。
    • 
        
  • 流式响应：可以逐步展示 Token，但要处理断线、取消、重复事件和未完成输出。
    • 
        
  • 共同要求：都需要超时、日志、Token 预算、输出校验和敏感信息保护。
    • 
      

    

    

      
错误处理清单

      
    
        
  • 认证失败：停止请求并检查服务端凭证配置，不向客户端返回密钥细节。
    • 
        
  • 限流：读取可用的重试提示，指数退避并限制总次数。
    • 
        
  • 超时或断线：取消上游请求，保留可追踪状态，允许用户重新发起。
    • 
        
  • 上下文超限：缩短输入、摘要历史或拒绝请求，不能无限截断关键内容。
    • 
        
  • 校验失败：对安全的请求有限重试，否则进入降级或人工处理。
    •
