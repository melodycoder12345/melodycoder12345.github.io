推理与 KV Cache

在线推理不是一次函数调用，而是 tokenize、prefill、缓存、逐 token decode、采样和流式返回的长链路。KV Cache 用空间换时间，是 LLM 服务吞吐和延迟优化的核心。

后续 token 贵decode 每步只处理新 token，但要反复读写每层 KV Cache。

工程意义
Prefill 更像一次大矩阵批处理，Decode 更像大量小步循环。高吞吐服务会把请求合批、拆分 prefill/decode 队列，并用 continuous batching 降低 GPU 空转。
失败模式
  • 上下文被 RAG 塞满后，首 token 延迟和显存占用同时上升。
  • cache eviction 或请求取消处理不好，会造成显存泄漏或尾延迟抖动。
