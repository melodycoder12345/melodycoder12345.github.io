推理瓶颈

Memory-Bound 问题

LLM 推理慢的核心原因：Attention 计算需要反复从 HBM（显存）读取庞大的 KV Cache，而 HBM 带宽远低于 GPU 算力（算力 > 内存带宽，称 memory-bound）。

自回归串行瓶颈

LLM 每次只生成一个 Token，下一个 Token 依赖上一个的结果，无法并行化。这是推理速度的根本限制。

优化技术对比

Speculative Decoding

用小模型（draft model）并行猜 N 个 Token，大模型一次前向传播并行验证。接受率高时加速 2-3x，适合大小模型能力差距不大的场景。

FlashAttention

IO 感知的分块矩阵乘法，减少 HBM 读写次数。不改变计算结果，只改变计算顺序。训练和推理都有效，已成为标准实现。

PagedAttention

虚拟化 KV Cache 内存管理，消除碎片化，支持不同请求动态共享物理内存页（Prefix Caching）。vLLM 核心技术。

Continuous Batching

请求完成即插入新请求，不等整个 batch 完成。将 GPU 利用率从 40-60% 提升到 80%+。

关键指标
TTFT（Time To First Token）：第一个 Token 的延迟，影响用户感知响应速度。
TPS（Tokens Per Second）：吞吐量，影响服务成本。两者往往需要权衡。
