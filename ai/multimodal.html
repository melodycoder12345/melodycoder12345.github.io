多模态 AI

多模态 AI 让模型能同时理解和生成图像、文本、音频、视频等不同类型内容。核心挑战是异质特征空间的对齐：如何让"一只猫的照片"和"a photo of a cat"在同一个向量空间中表示为相近的点。CLIP 的对比预训练、ViT 的图像 tokenization、跨模态注意力机制是现代多模态架构的三块基石，理解它们是读懂 GPT-4V、Gemini、DALL-E 3、Stable Diffusion 的前提。

CLIPViTCross-Attention扩散模型视觉语言模型多模态对齐
核心术语
  • CLIP对比训练图文编码器，4 亿图文对对齐语义空间。
  • 跨模态注意力文本 Query 对图像 Key/Value 做注意力，融合两种特征。
  • ViT（Vision Transformer）图像切 patch 后展平为 token 序列送入 Transformer。
  • 多模态幻觉生成与图像不符的文字，语言先验过强的典型问题。

CLIP：对比语言-图像预训练

  • 核心思想：将图像和文本映射到同一嵌入空间，用对比损失（InfoNCE）让匹配图文对的余弦相似度最大化，非匹配对最小化
  • 架构：图像侧用 ViT（或 ResNet），文本侧用 GPT-like Transformer，分别输出 L2 归一化向量
  • 训练数据：4 亿条从网络爬取的图文对（alt text + 图片），数据噪声大但规模弥补质量
  • Zero-shot 分类：将类别名写成模板（"a photo of {class}"），用文本编码器编码后与图像向量比相似度，无需微调即可分类
  • 局限：对细粒度视觉关系（"左边的红色球在右边的蓝色立方体上方"）理解弱，对 OCR 文字识别效果差
CLIP 对 Stable Diffusion 的重要性：SD 的 text encoder 就是 CLIP ViT-L/14，文本 prompt 经过 CLIP 编码后作为条件信号指导扩散模型的去噪方向。

ViT：图像的 Tokenization

  • Patch 划分：将 224×224 图像切成 14×14=196 个 16×16 的 patch，每个 patch 展平为 256 维向量后线性投影
  • [CLS] token：类似 BERT 的 [CLS]，附加在 patch 序列头部，最终输出代表整图的全局特征
  • 位置编码：ViT 用可学习的 1D 位置编码（不是 2D），实验表明模型自己学到了 2D 空间关系
  • ViT 变体：ViT-B（12层 768维）、ViT-L（24层 1024维）、ViT-H（32层 1280维），CLIP 使用 ViT-L/14
  • 分辨率外推：推理时用更高分辨率（如 336px），patch 数量增加，位置编码用双线性插值扩展
# ViT patch 编码伪代码 def encode_image(img): # img: [B, C, H, W] patches = split_patches(img, size=16) # [B, 196, 256] x = linear_proj(patches) # [B, 196, 768] cls = self.cls_token.expand(B, -1, -1) # [B, 1, 768] x = cat([cls, x], dim=1) # [B, 197, 768] x = x + self.pos_embed # 加位置编码 return transformer(x)[:, 0] # 取 CLS token

视觉语言模型（VLM）架构

🖼️
Image
高分辨率图像切 patch，ViT 编码为 patch embeddings
🔗
Projector
MLP / Q-Former 将视觉特征投影到 LLM 词向量空间
🤖
LLM
将图像 token 拼入文本 token 序列，自回归生成答案
  • LLaVA 架构：ViT（CLIP 编码器）+ 线性 Projector + Vicuna/LLaMA，用 ShareGPT4V 数据微调
  • Flamingo（DeepMind）：冻结视觉/语言编码器，用 Gated Cross-Attention 层间插入，保留语言模型原有能力
  • GPT-4V：细节未公开，推测用高分辨率图像切成 512px tile 分别编码再拼接
  • Q-Former（BLIP-2）：用可学习的 query token 从视觉特征中提取固定数量的信息，减少视觉 token 数量

文生图：扩散模型与多模态条件

  • Stable Diffusion 管道：Text → CLIP Encoder → Text Embeddings → UNet 去噪（条件：通过 cross-attention 注入 text embeddings）→ VAE Decoder → Image
  • Classifier-Free Guidance（CFG）：同时运行有条件和无条件去噪，输出 = uncond + scale × (cond - uncond)，scale 越大图像越忠于 prompt 但多样性越低
  • DALL-E 3 改进：用 ChatGPT 重写用户 prompt 提高语义对齐，训练数据包含高质量 dense caption
  • ControlNet：通过边缘图/深度图/姿态骨架等结构信号额外约束生成，解决扩散模型布局控制弱的问题
  • DiT（Diffusion Transformer）：用 Transformer 替代 UNet 作为去噪网络骨架，Sora 使用的架构变体
CFG 本质是在推理时做引导梯度上升——从噪声中走向符合 prompt 描述的方向，scale=7~10 是常见经验值。scale 过高会出现过饱和、细节丢失。

多模态理解：视频与音频

  • 视频理解挑战：时序建模（帧间运动关系）、计算量（1 分钟 720p 视频 = 1800 帧 × 196 patch = 352,800 token）、长视频关键帧稀疏采样
  • Video-LLaMA / VideoChat：时序编码器（Video Q-Former）从视频帧中提取时序特征后送入 LLM，类似图像 VLM 但增加了帧间注意力
  • Whisper（音频）：将音频转为 log-mel 频谱图（像"声音的图片"），用 CNN + Transformer 编码后送入 Transformer decoder 生成文字
  • 多模态对话（Gemini 1.5）：原生多模态架构，支持 1M token 上下文，可直接处理小时级视频

工程挑战与局限

  • 视觉 token 数量：一张图 = 196~256 个 patch token，对 LLM 的 context window 压力大；常用动态分辨率裁剪和 token 压缩（如 AnyRes）
  • 细粒度空间理解：VLM 对"A 在 B 左边"、"图中有几个 X"等计数/关系问题仍然不稳定，是主要 benchmark gap
  • 多模态幻觉：模型生成图中不存在内容的原因：语言先验（见过的文字模式）强于视觉信号，解法是对比解码和视觉链式思维（SoM）
  • OCR 和文档理解：通用 ViT 对文档中文字识别弱，GOT、DocOwl 等专用模型用高分辨率 patch 和 OCR 预训练改善
  • 训练数据对齐：图文对的质量决定 CLIP 表示质量，网络爬取的 alt text 噪声大，高质量 dense caption（如 ShareGPT4V）能显著提升细粒度理解
视觉 token 压缩是 2024-2025 年的热点：从原始 196 patch token 压缩到 64 个（LLaVA-OneVision），在减少计算量的同时保持关键视觉信息。
