最小 PyTorch 骨架
class MiniGPT(nn.Module):
    def __init__(self, vocab, dim, block_size):
        super().__init__()
        self.token = nn.Embedding(vocab, dim)
        self.position = nn.Embedding(block_size, dim)
        self.block = TransformerBlock(dim)
        self.lm_head = nn.Linear(dim, vocab)

    def forward(self, ids, targets=None):
        _, time = ids.shape
        x = self.token(ids) + self.position(torch.arange(time))
        logits = self.lm_head(self.block(x))
        loss = None if targets is None else F.cross_entropy(
            logits.reshape(-1, logits.size(-1)), targets.reshape(-1))
        return logits, loss
教学模型不等于生产模型
  • 真实模型包含很多层、更多 Attention Head 和更大词表。
  • 真实训练还需要数据治理、混合精度、分布式并行、Checkpoint 和系统评测。
  • 本页目标是让你能解释每个张量为什么存在，而不是训练出可用助手。
