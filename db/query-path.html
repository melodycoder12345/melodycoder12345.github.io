追踪 SQL： SELECT name FROM users WHERE age > 25 ORDER BY age LIMIT 10
📄 SQL 文本 ✓
原始字符串输入
SELECT name FROM users WHERE age > 25 ORDER BY age LIMIT 10
▼
🔤 词法分析 Lexer ✓
字符流 → Token 序列
[SELECT] [name] [FROM] [users] [WHERE] [age] [>] [25] [ORDER BY] [age] [LIMIT] [10]
▼
🌲 语法分析 Parser ✓
Token流 → 抽象语法树 AST
SelectStmt ├─ Fields : [name] ├─ From : users ├─ Where : BinaryExpr(age > 25) ├─ OrderBy : [age ASC] └─ Limit : 10
▼
📐 逻辑计划 Logical Plan ✓
关系代数树，与具体实现无关
Limit(10) → Sort(age) → Filter(age>25) → SeqScan(users)
▼
📊 代价估算 Cost Estimation ✓
统计信息 + 直方图 → 估算各方案代价
users表 10万行，age列有索引 IndexScan cost=31 < SeqScan cost=8200 → 选择 IndexScan(idx_age)
▼
⚙️ 物理计划 Physical Plan ✓
可直接执行的算子树
Limit(10) → Sort(age) → IndexScan(users.idx_age, age>25)
▼
🌿 执行：索引扫描 ✓
B+ 树遍历，定位 age > 25 的叶节点
idx_age B+ 树: 找到 age=26 入口叶节点 顺序扫描叶节点链表 → 收集 row_id 列表
▼
💾 执行：获取数据页 ✓
row_id → Buffer Pool → 数据行
bufPool.GetPage(rid.PageID) 命中 → 直接读内存；未命中 → disk.ReadPage() 16KB
▼
✅ 返回结果 ✓
排序 + Limit → 10行 name 字段返回客户端
sort.Slice(rows, age ASC) result = rows[:10] → 返回给客户端
