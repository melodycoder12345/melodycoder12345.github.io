System Design
分布式 ID
Snowflake · 时钟回拨 · Leaf 号段模式
步骤说明
选择场景，了解分布式 ID 的生成原理和时钟回拨处理方案。
Snowflake 位布局
符号位 (1 bit)始终为 0
时间戳 (41 bit)毫秒级，69 年
数据中心 (5 bit)最多 32 个 DC
机器 ID (5 bit)每 DC 最多 32 台
序列号 (12 bit)同毫秒 4096 个
理论上单台机器每毫秒可生成 4096 个 ID，1024 台机器集群每秒可生成约 40 亿个 ID。
时钟回拨应对

方案一：等待

检测到回拨时，等待时钟追上上次记录的时间再继续生成。适合回拨时间极短（<10ms）的场景。

方案二：抛出异常

检测到回拨直接抛出异常，让上游重试。适合对 ID 单调递增有强要求的场景。

方案三：拓展位

减少序列号位数，挪 3 位给"回拨标记位"，回拨时递增标记位，换空间换时间单调性。

Leaf 号段模式

核心思路

每次从 DB 获取一段 ID（如 [1000, 2000)），在内存中依次分配，避免每次生成都访问数据库。DB 只需承受 1/1000 的写压力。

双 Buffer 优化

当前号段使用到 10% 时，异步预加载下一个号段到 Buffer B。号段用尽时直接切换，消除等待 DB 的延迟抖动。
