核心数据结构
📋 倒排索引
词 → Posting List（文档 ID + 词频 + 位置）。词典查找成本取决于 FST/哈希/树等实现与词长，之后还要解码和遍历 Posting List。
📊 BM25 算法
改进版 TF-IDF，加入文档长度归一化。score = IDF × TF×(k1+1) / (TF + k1×(1-b+b×L/avgL))。k1=1.2, b=0.75 是典型参数。
🔗 PageRank
网页权威度 = 0.15 + 0.85 × Σ(PageRank(入链页)/出链数)。迭代收敛后反映页面在网络中的重要性，与 BM25 结合用于最终排序。
倒排索引存储

Lucene 存储格式

词典存入 FST（有限状态转换器），Posting List 用 Delta 编码 + VByte 压缩。词典常驻内存，Posting List 按需加载磁盘。

Elasticsearch 基于 Lucene，Shard 即一个 Lucene 实例。查询时并行搜索所有 Shard，协调节点合并结果。

分词器

中文分词：jieba（精确模式/全模式/搜索引擎模式）或 IK Analyzer（ES 常用）。英文：标准空格分词 + Stemming（词干化）。

分布式搜索

Scatter-Gather 模式

协调节点将查询广播到所有 Shard（Scatter），每个 Shard 本地检索后返回 Top-K，协调节点归并排序（Gather）取全局 Top-K。
