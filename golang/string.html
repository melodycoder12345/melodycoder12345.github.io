字符串底层结构

StringHeader：两字段结构

核心

Go 语言把 string 定义为不可变的任意字节序列，不要求内容一定是有效 UTF-8。常见实现用数据指针和字节长度表示；reflect.StringHeader 只适合解释这种布局，不是稳定的运行时契约。

// runtime/string.go（简化）
type StringHeader struct {
    Data uintptr  // 示意：指向字符串字节
    Len  int      // 字节数（不是字符数）
}

s := "hello"
h := (*reflect.StringHeader)(unsafe.Pointer(&s))
fmt.Println(h.Len)   // 5

字符串赋值只拷贝这 16 字节的 header（指针+长度），不拷贝底层字节数据，所以赋值是 O(1) 的。字符串拼接才会分配新内存。

rune vs byte

UTF-8 编码与字符迭代

核心

Go 源码使用 UTF-8 编码。ASCII 字符占 1 字节，中文等 CJK 字符占 3 字节，emoji 占 4 字节。

  • len(s)：返回字节数（UTF-8 编码后的字节总数）
  • s[i]：返回第 i 个字节（byte），不是第 i 个字符
  • for i, r := range s：按 Unicode 码点（rune）迭代，i 是字节偏移
s := "Go语言"
fmt.Println(len(s))           // 8（2 + 3 + 3）
fmt.Println(len([]rune(s)))  // 4（字符数）

for i, r := range s {
    fmt.Printf("[%d] %c (%d bytes)\n", i, r, utf8.RuneLen(r))
}
// [0] G (1 bytes)
// [1] o (1 bytes)
// [2] 语 (3 bytes)
// [5] 言 (3 bytes)

strings 包常用函数

核心
  • strings.Contains(s, sub) — 是否包含子串
  • strings.HasPrefix/HasSuffix — 前缀/后缀检查
  • strings.Split(s, sep) — 按分隔符分割

  • strings.ToLower/ToUpper — 大小写转换

strings.Builder

高效字符串构建

进阶

Go 1.10 引入 strings.Builder，专为字符串拼接优化。内部维护 []byte，调用 String() 时通过 unsafe 零拷贝转换为 string，避免额外内存分配。

var b strings.Builder
b.Grow(64)  // 预分配容量，减少扩容次数

for i := 0; i < 10; i++ {
    fmt.Fprintf(&b, "item%d,", i)  // 实现 io.Writer
    b.WriteString("sep")           // 写字符串
    b.WriteByte('\n')              // 写单字节
    b.WriteRune('龙')              // 写 Unicode 字符
}

result := b.String()  // 零拷贝转换
b.Reset()             // 重置为空；当前实现释放对缓冲区的引用

注意：非零 Builder 在第一次使用后不能再按值复制；通常在原值上继续调用其方法。如果需要并发写，需要外部同步。

面试题

string 的底层结构是什么？为什么是不可变的？▶
语言层面，string 是不可变的字节序列；常见实现由数据指针和长度组成，但具体布局不是应用代码应依赖的契约。这种语义使得：
1. 字符串赋值/传参只拷贝 header，O(1) 操作
2. 多个字符串可以安全共享底层数据（子串切片时）
3. 不需要加锁，天然并发安全
如果需要修改，需转换为 []byte（会发生内存拷贝）修改后再转回 string。
修改 string 中某个字符的方法？▶
Go 的 string 不可变，不能直接 s[i] = 'x'。修改方法：
1. 转换为 []byte，修改后转回：b := []byte(s); b[0] = 'X'; s = string(b)（有两次内存拷贝）
2. 如果处理 Unicode，转换为 []rune 修改后转回（处理中文等多字节字符）
3. 使用 strings.Map/strings.Replace 等函数式方法
注意：每次 string ↔ []byte 转换都会发生内存拷贝，频繁修改的场景直接用 []byte 操作。
[]byte 和 string 互转的内存开销？▶
通常情况下，string([]byte) 和 []byte(string) 都会发生内存拷贝，时间复杂度 O(n)。

但 Go 编译器对以下场景做了优化（零拷贝）：
• m[string(b)]：map 查找时的 key 转换
• switch string(b) {}：switch 语句的比较
• for range string(b)：range 遍历
• 字符串比较 string(b) == "foo"

如果需要真正零拷贝转换，需要借助 unsafe.Pointer，但有内存安全风险，生产代码需谨慎。
为什么 strings.Builder 比 bytes.Buffer 更适合构建字符串？▶
两者都用 []byte 做底层存储，写入性能相近。关键区别在于获取最终字符串时：
• bytes.Buffer.String()：调用 string(b.buf[b.off:])，发生一次内存拷贝
• strings.Builder.String()：通过 unsafe 包将 []byte 指针直接转换为 string，零拷贝

另外 Builder 不支持 Read 操作，API 更简洁。如果需要同时读写或实现 io.ReadWriter，用 bytes.Buffer；单纯构建字符串用 Builder。
如何高效统计 UTF-8 字符串的字符数？▶
三种方法，推荐第一种：
1. utf8.RuneCountInString(s)：标准库，O(n) 遍历字节，不分配内存
2. len([]rune(s))：先将字符串转换为 rune slice（会分配内存），再取长度，不推荐
3. for range s：手动计数，等价于方法1

len(s) 返回字节数，对于纯 ASCII 字符串 len(s) == 字符数，但对包含中文的字符串则不等。

易错点

❌ len() 返回字节数，不是字符数
s := "你好"
fmt.Println(len(s))  // 6，不是 2！

// 错误地按字节截取
first := s[:1]  // 乱码！

中文字符每个占 3 字节，len() 返回字节总数 6。

s := "你好"
runes := []rune(s)
fmt.Println(len(runes))  // 2 ✓

// 或使用标准库
import "unicode/utf8"
fmt.Println(utf8.RuneCountInString(s)) // 2

用 utf8.RuneCountInString 或转 []rune 后取 len。

❌ for i 与 for i,v range 遍历行为不同
s := "Go语"
// for i — 按字节遍历
for i := 0; i < len(s); i++ {
    fmt.Printf("%x ", s[i])
}
// 47 6f e8 af ad
// "语" 的3字节被分别输出

for i 循环按字节遍历，中文字符会被拆开。

s := "Go语"
// for range — 按 rune 遍历
for i, r := range s {
    fmt.Printf("[%d]%c ", i, r)
}
// [0]G [1]o [2]语
// i 是字节偏移，r 是完整字符

for range 自动解码 UTF-8，正确处理多字节字符。

❌ 循环中用 + 拼接字符串性能差
// 错误：O(n²) 的内存分配
result := ""
for i := 0; i < 10000; i++ {
    result += fmt.Sprintf("item%d\n", i)
}
// 每次迭代都分配新字符串

每次 += 都创建新的字符串对象，O(n²) 内存操作。

// 正确：使用 strings.Builder
var b strings.Builder
b.Grow(10000 * 10)  // 预分配
for i := 0; i < 10000; i++ {
    fmt.Fprintf(&b, "item%d\n", i)
}
result := b.String()  // O(n) 总计

strings.Builder 预分配容量后，均摊 O(1) 写入，最终一次性转换字符串。

❌ 字符串转换后修改 []byte 影响原字符串（不会！但要理解原因）
s := "hello"
b := []byte(s)
b[0] = 'H'
// 误以为 s 会变成 "Hello"
fmt.Println(s)  // "hello"（不变）

string→[]byte 会发生内存拷贝，b 是独立的副本，修改 b 不影响 s。

s := "hello"
b := []byte(s)  // 拷贝
b[0] = 'H'
s = string(b)  // 再拷贝回来
fmt.Println(s)  // "Hello" ✓

// 如果只需要修改，直接操作 []byte
// 不必来回转换 string

需要明确：string 不可变，转换总有拷贝。如需频繁修改，整个流程用 []byte。
