OpenTelemetry

可观测性领域的统一标准。OpenTelemetry（OTel）提供统一的 API 和 SDK，一次插桩同时采集 Trace、Metric、Log 三类信号，通过 Collector 做统一处理和路由，输出到任意后端（Jaeger / Prometheus / Loki / Datadog）。彻底解决各厂商 SDK 不兼容、迁移成本高的问题。
