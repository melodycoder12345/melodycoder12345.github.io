Docker 镜像分层

每条 Dockerfile 指令产生一个只读层，层之间共享，容器运行时叠加可写层。OverlayFS 的 lowerdir/upperdir/workdir 机制使镜像复用高效。

OverlayFSCopy-on-WriteLayer
☸↗

K8s 控制面

kubectl apply → API Server 认证鉴权 → etcd 持久化 → Controller Watch → Scheduler 调度 → kubelet 拉起容器。所有组件通过 etcd 事件解耦，无需直接调用。

etcdControllerScheduler
📦↗

Pod 调度

Filter 阶段淘汰不满足条件的节点（资源/Taint/Affinity），Score 阶段为剩余节点打分加权，最高分节点绑定 Pod。

FilterScoreTaintAffinity
🔗↗

Service 网络包路径

从 Pod 发出的请求如何经过 veth pair → cbr0 网桥 → iptables/IPVS 规则 → 目标 Pod。ClusterIP 是虚拟 IP，真正转发由 iptables DNAT 规则完成。

CNIiptablesClusterIPIPVS
📈↗

弹性伸缩 HPA

CPU 使用率超过阈值，HPA 控制器计算目标副本数，Deployment 扩容，冷却期内抑制过频扩容，缩容延迟避免流量抖动。

HPAmetrics-servercooldown

学习路径建议

建议从 Docker 镜像分层（理解容器的基础机制）开始 → K8s 控制面（理解声明式 API 和 Watch 机制）→ Pod 调度（资源管理）→ Service 网络（流量如何路由）→ HPA 弹性伸缩（生产环境扩缩容策略）。Linux 模块的容器原理页面是本模块的前置知识。
