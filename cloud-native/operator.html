Kubernetes Operator

Operator 是 K8s 原生的扩展机制：通过自定义资源（CRD）描述业务意图，自定义 Controller 实现 Reconcile 循环持续将实际状态拉向期望状态。Operator 让 K8s 能管理有状态应用（数据库、消息队列等），将运维知识编码为代码。
