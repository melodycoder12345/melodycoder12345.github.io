Linux / cgroup / B 类型

cgroup / Namespace

Namespace 改变进程看到的系统视图，cgroup 限制资源用量，两者构成容器基础。

cgroup v2NamespaceContainer
B 类型页面重点是把背景、术语、机制、误区和工程场景讲清楚；本页不强行加入动画。
核心术语
Namespace隔离 PID、mount、network、UTS、IPC、user 等视图。
cgroup限制和统计 CPU、memory、I/O 等资源。
rootfs容器看到的文件系统根。

背景

容器不是虚拟机，它共享宿主机内核。隔离来自 namespace 的视图隔离和 cgroup 的资源控制。

运行机制

  • 创建 namespace，让进程看到独立的进程树、网络栈或挂载点。
  • 把进程加入 cgroup，设置 CPU、内存和 I/O 配额。
  • 运行时挂载 rootfs 并启动进程。

常见误区

  • 容器共享宿主机内核，内核漏洞会突破隔离边界。
  • 内存限制包含 Page Cache，排查 OOM 时不能只看堆。

工程场景

  • Docker、Kubernetes、systemd slice 和资源隔离排障都依赖这组机制。

边界判断

判断这个概念是否适用时，先看它解决的核心约束，再看代价是否落在业务可接受范围内。不要只记名字，要能说清楚它牺牲了什么、保留了什么。

学习路径
