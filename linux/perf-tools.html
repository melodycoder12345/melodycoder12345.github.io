性能工具

Linux 性能分析遵循 USE 方法论（利用率/饱和度/错误），工具链覆盖 CPU（perf/top）、内存（vmstat/smem）、IO（iostat/iotop）、网络（ss/tcpdump）、系统调用（strace/ltrace）、全系统观测（eBPF/bpftrace）。火焰图是 CPU 热点可视化的标准工具。掌握这些工具可系统性地定位生产环境性能问题。

perfeBPFbpftrace火焰图stracetcpdumpUSE
核心术语
  • USE 方法论利用率/饱和度/错误，系统性检查每个资源。
  • eBPF内核沙盒，零侵入 hook 任意内核事件。
  • 火焰图CPU profiling 可视化，宽度=时间占比，找热点。
  • perf stat硬件计数器（cache miss/分支误判/IPC）。

CPU 性能工具

top / htop
进程 CPU/内存占用，%us/%sy/%wa 看用户/内核/等待IO占比
perf stat
硬件事件计数：IPC、L1/LLC cache miss率、分支误判率
perf record/report
采样 CPU 时间，生成调用栈，输出热点函数
flamegraph.pl
将 perf/dtrace 输出转为 SVG 火焰图
# 采集 30s CPU profile perf record -F 99 -ag -- sleep 30 perf script | stackcollapse-perf.pl | flamegraph.pl > cpu.svg # 硬件计数器 perf stat -e cache-misses,cache-references,cycles,instructions \ ./program

内存性能工具

  • vmstat 1：每秒内存统计，关注 si/so（swap in/out）和 buff/cache 比例
  • free -h：Mem/Swap 使用量，available 才是真正可用的
  • smem：按 PSS（Proportional Set Size）计算共享内存，比 RSS 更准确
  • pmap -x PID：进程内存映射详情，找出大内存段
  • /proc/meminfo：内核内存详细统计（PageTables/Shmem/SReclaimable）
  • valgrind/AddressSanitizer：检测内存泄漏和越界访问（有开销，不适合生产）
  • bpftrace 内存泄漏检测：追踪 malloc/free 不匹配，生产环境可用

磁盘 IO 工具

  • iostat -xz 1：每秒磁盘统计，%util（利用率）接近 100% 说明 IO 饱和
  • iotop：进程级 IO 速率，找出 IO 密集进程
  • blktrace / biosnoop (eBPF)：块级 IO 追踪，延迟分布，区分读/写/同步
  • fio：磁盘性能基准测试，测量顺序/随机读写 IOPS 和带宽
  • 关键指标：await（平均等待时间）> 10ms 说明 IO 延迟高；%util 反映忙碌程度
  • ext4/xfs 日志：写密集场景关注 journal 锁竞争（dmesg 中的 ext4 警告）

网络诊断工具

  • ss -tnp：查看所有 TCP 连接状态，比 netstat 更快，支持过滤
  • tcpdump / Wireshark：抓包分析，诊断 TCP 重传、连接失败、TLS 握手问题
  • ip -s link：网卡统计，TX/RX 字节、包数、错误、丢包
  • ping / traceroute / mtr：延迟和路径追踪，mtr 持续追踪丢包位置
  • iperf3：测量两点间 TCP/UDP 吞吐量基准
  • conntrack -L：查看 NAT 连接跟踪表，诊断 conntrack 满导致的丢包

eBPF / bpftrace 工具链

  • bpftrace：awk-like 脚本语言，一行命令 hook 内核事件
  • BCC Tools：预置工具集，biolatency/tcpretrans/runqlat/offcputime
  • runqlat：进程在 CPU 调度队列等待时间分布（诊断调度延迟）
  • offcputime：进程在 OFF-CPU 的时间（I/O 等待、锁等待、sleep）
  • tcpretrans：实时追踪 TCP 重传，显示源/目的 IP 和原因
  • memleak：追踪内存分配未释放的调用栈
# 追踪系统调用延迟 > 10ms bpftrace -e 'tracepoint:raw_syscalls:sys_exit { @[comm] = hist(nsecs - @start[tid]); delete(@start[tid]); }' # 查看 read 系统调用延迟直方图 biolatency -D # 磁盘 IO 延迟直方图

系统调用与进程追踪

  • strace -p PID：追踪进程系统调用，-c 统计各调用耗时
  • ltrace：追踪库函数调用（如 malloc/pthread_mutex）
  • gdb / rr：调试器，rr 支持时间旅行调试（record + replay）
  • lsof -p PID：进程打开的文件/socket 列表
  • /proc/PID/fd：进程文件描述符，诊断文件描述符泄漏
  • perf sched：调度器分析，延迟唤醒、上下文切换开销
  • 生产环境优先用 eBPF（零侵入），开发环境用 strace/gdb（有开销但信息更全）
